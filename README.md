# غيم — موقع ملابس أطفال

موقع ثابت (بدون خادم أو قاعدة بيانات) لعلامة «غيم» في الرياض.

## الملفات

| الملف | الوصف |
| --- | --- |
| `index.html` | الصفحة الرئيسية: ترحيب، 3 مميزات، صور، آراء، زر واتساب ثابت |
| `clothes.html` | ملابس الأطفال: ملابس نوم، ملابس بنات، ملابس أولاد |
| `about.html` | عنّا: الحكاية والقيم وخطوات الوصول |
| `contact.html` | تواصل: واتساب، هاتف، بريد، ساعات العمل، خريطة Google مضمّنة، أسئلة متكررة |
| `en.html` | النسخة الإنجليزية من الرئيسية (`dir="ltr"`) |
| `style.css` | التنسيقات المشتركة لكل الصفحات |
| `assets/` | صور المنتجات في `assets/products/`، ورسومات SVG للزينة، والأيقونة |

## التشغيل

افتح `index.html` في المتصفح مباشرة. لا يحتاج المشروع إلى تثبيت أو بناء.
